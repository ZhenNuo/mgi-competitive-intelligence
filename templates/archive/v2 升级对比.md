# MGI 竞争情报报告模板 - v2.0 升级对比

**更新日期**: 2026-03-12

---

## 📊 三日报模板对比

### v1 模板结构

```
1. 报告周期
2. 核心发现摘要
3. 竞品动态详情（按品牌罗列）
4. 时间序列数据更新
5. 监管与审批动态
6. 财务与业绩
7. 数据源说明
8. 风险提示
9. 后续行动建议
```

### v2 模板结构

```
1. 报告元信息（期号/置信度）
2. 🚨 核心摘要（30 秒速读 + 优先级表格）
3. 🔥 重大异动（需立即关注）
4. 📊 竞品动态详情（按区域划分）
5. 🏛️ 监管与审批
6. 💰 财务与资本动态
7. 📈 时间序列指标追踪
8. ⚠️ 风险与机会预警
9. 📋 后续行动建议（责任人 + 截止时间）
10. 📝 数据源说明（含验证状态）
```

### 核心改进点

| 维度 | v1 | v2 | 改进价值 |
|------|----|----|----------|
| **阅读效率** | 需要通读全文 | 30 秒速读核心摘要 | ⬆️ 节省 60-70% 时间 |
| **信息组织** | 按品牌罗列 | 按区域 + 优先级分层 | ⬆️ 更清晰的市场视角 |
| **置信度管理** | 文末统一说明 | 每条动态单独标注 | ⬆️ 避免信息误导 |
| **行动指导** | 简单列举建议 | 明确责任人 + 截止时间 | ⬆️ 更强的可执行性 |
| **风险预警** | 简单风险提示 | 风险 + 机会双维度 | ⬆️ 更全面的决策支持 |
| **趋势可视化** | 简单表格 | 时间序列 + 趋势标识 | ⬆️ 更直观的变化追踪 |

## 📊 周报模板对比

### v1 模板结构

```
1. 报告期信息
2. 核心摘要
3. 国内市场动态
4. 海外市场动态
5. 核心竞争指标对比
6. 竞争风险预警
7. 下一期追踪重点
8. 数据来源附录
```

### v2 模板结构

```
1. 报告元信息（期号/类型/置信度）
2. 📋 执行摘要（1 分钟速读 + 关键指标）
3. 🎯 本周深度分析（1-2 个主题）
4. 🌍 区域市场深度追踪
   - 中国市场（招投标 + 集采 + 竞品情报）
   - 北美市场（趋势 + 政策 + 玩家动态）
   - 欧洲市场（监管 + 合规 + 玩家动态）
   - 亚太及新兴市场
5. 📊 产品与技术对标
   - 本周产品动态
   - 技术路线对比
   - 专利与知识产权
6. 💰 财务与资本追踪
   - 融资与并购
   - 财报关键指标对比
7. 🏛️ 政策与监管环境
   - 国内政策
   - 国际政策
8. 🔍 竞争格局演变
   - 市场份额变化
   - 竞争态势矩阵
9. ⚠️ 风险与机会评估
10. 📋 战略建议与行动计划
    - 立即行动（本周内）
    - 短期规划（1-4 周）
    - 中长期研究课题
11. 📈 时间序列数据库更新
12. 📝 数据源与验证说明
```

### 核心改进点

| 维度 | v1 | v2 | 改进价值 |
|------|----|----|----------|
| **报告定位** | 信息汇总 | 深度分析 + 决策支持 | ⬆️ 更高战略价值 |
| **分析深度** | 浅层描述 | 深度分析框架 | ⬆️ 更强洞察力 |
| **区域覆盖** | 国内/海外二分 | 四大区域精细划分 | ⬆️ 更精准的市场洞察 |
| **产品技术** | 简单对比表 | 产品 + 技术 + 专利三维 | ⬆️ 更全面的技术情报 |
| **财务追踪** | 无 | 融资/并购/财报对比 | ⬆️ 更完整的资本视角 |
| **政策监管** | 无 | 国内/国际政策分析 | ⬆️ 更强的合规意识 |
| **行动建议** | 简单列举 | 立即/短期/中长期分层 | ⬆️ 更系统的执行路径 |
| **竞争格局** | 简单预警 | 份额 + 态势矩阵 | ⬆️ 更清晰的竞争全景 |

## 🔧 模板使用建议

### 三日报

**适用场景**:
- ✅ 日常竞品动态监控
- ✅ 快速识别重大异动
- ✅ 短期行动决策

**不适用场景**:
- ❌ 深度战略分析（用周报）
- ❌ 长期趋势研判（用月度/季度报告）
- ❌ 全面竞争格局（用周报）

### 周报

**适用场景**:
- ✅ 战略决策参考
- ✅ 产品规划与研发
- ✅ 市场策略制定
- ✅ 资本运作参考
- ✅ 全面竞争格局分析

**不适用场景**:
- ❌ 日常快讯（用三日报）
- ❌ 紧急异动响应（用三日报）
