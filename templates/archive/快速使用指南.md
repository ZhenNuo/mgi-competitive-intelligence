## 🚀 快速开始

### 三日报使用

```bash

cp ~/Desktop/MGI-Competitive-Intelligence/templates/三日报模板_v2.md \
   ~/Desktop/MGI-Competitive-Intelligence/daily-reports/三日报_YYYY-MM-DD.md

# 2. 编辑填充（使用查找替换所有 {{变量}}）
```

## 📋 核心变量说明

### 通用变量

| 变量 | 说明 | 示例 |
|------|------|------|
| `{{start_date}}` | 报告周期开始日期 | 2026-03-08 |
| `{{end_date}}` | 报告周期结束日期 | 2026-03-11 |
| `{{delivery_date}}` | 交付日期 | 2026-03-12 |
| `{{issue_number}}` | 期号 | 02 |
| `{{generation_time}}` | 报告生成时间 | 2026-03-12 16:30 CST |
| `{{cutoff_time}}` | 数据截止时间 | 2026-03-12 16:00 CST |
| `{{next_report_date}}` | 下次报告日期 | 2026-03-15 |

### 内容变量

| 变量 | 说明 | 填写提示 |
|------|------|----------|
| `{{competitor}}` | 竞品名称 | 贝克曼/Hamilton/领坤等 |
| `{{type}}` | 动态类型 | 产品发布/融资/合作/监管等 |
| `{{description}}` | 动态详情 | 2-3 句话描述 |
| `{{source}}` | 信息来源 | 官方新闻稿/行业媒体/财报等 |
| `{{level}}` | 置信度 | A/B/C/D |
| `{{impact}}` | 影响评估 | 高/中/低 + 影响维度 |
| `{{action_recommendation}}` | 建议行动 | 具体可执行动作 |

## 🎯 最佳实践

### 1. 数据采集

**优先数据源**（按置信度排序）:
1. 竞品官网/财报/公告（A 级）
2. 监管机构公示（A 级）
3. 头部券商行研（B 级）
4. 权威行业媒体（C 级）

**避免数据源**:
- 自媒体/公众号（除非能追溯到一手源）
- 论坛/社群传闻
- 无法验证的网传信息

### 2. 置信度标注

**必须标注 A 级**:
- 财报数据
- 监管审批
- 官方公告
- 专利授权

**谨慎标注 B/C 级**:
- 媒体报道
- 行研报告
- 行业会议内容

**标注 D 级或剔除**:
- 单一来源且无法验证
- 自媒体传闻
- 明显夸大或矛盾信息

### 3. 交叉验证

**核心数据必须双源验证**:
- 市占率/装机量
- 融资金额
- 专利数量
- 审批进展

**验证方法**:
- 财报 + 第三方机构
- 官方公告 + 媒体报道
- 监管公示 + 行业新闻

### 4. 行动建议

**好建议的特征**:
- ✅ 具体可执行
- ✅ 明确责任人
- ✅ 有截止时间
- ✅ 可衡量结果

**避免空泛建议**:
- ❌ "持续关注"
- ❌ "加强监测"
- ❌ "深入研究"

### 5. 报告结构

**三日报**: 突出**快**和**准**
- 30 秒内能看完核心摘要
- 每条动态标注置信度
- 重大异动单独突出

**周报**: 突出**深**和**全**
- 至少 1 个深度分析主题
- 覆盖所有核心维度
- 提供战略建议
